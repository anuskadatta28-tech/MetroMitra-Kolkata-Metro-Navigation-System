# MetroMitra – Kolkata Metro Navigation System

## About the Project
MetroMitra is a C++ based Kolkata Metro Navigation System designed to help users find the best route between two metro stations.
The system uses Graphs and Dijkstra's Algorithm to calculate routes and provide information about station sequences, metro lines, interchange stations, estimated journey time, distance and ticket fare.

## Objectives
- Find the best metro route between source and destination.
- Display the complete sequence of stations.
- Identify metro lines and interchange stations.
- Calculate estimated travel time and distance.
- Calculate ticket fare.

## Key Features
- Source and destination station selection.
- Fastest route calculation.
- Metro line and interchange information.
- Complete station-by-station navigation.
- Estimated journey time and distance.
- Ticket fare calculation.

## Technologies Used
- C++
- Standard Template Library (STL)
- Graphs
- Dijkstra's Shortest Path Algorithm
- Object-Oriented Programming (OOP)

## Data Structures and Algorithms
- Graph – to represent metro stations and connections.
- Adjacency List – to store station connections.
- Priority Queue – to efficiently select the next station.
- Dijkstra's Algorithm – to find the shortest travel-time route.
- Vector and Unordered Map – for data storage and efficient lookup.
